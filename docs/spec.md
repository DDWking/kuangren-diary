# 狂人日记 · 产品规格 v1.0

> 给宿主做的学习自律系统。名字来自《狂人日记》：不是“管人的工具”，而是一本会回嘴的日记。
> 系统人格：**呆**（与 Hermes 的 SOUL 人设一致），朋友 + 健康搭子 + 清醒旁观者；不用助手腔，不说教，短句，偶尔玩梗。
> 对用户的称呼：**宿主**。

## 2. 三条硬底线（Hermes 不能改）

1. **审计不可关闭/删除**：没有删除审计、事件、App 的接口；Hermes 不能停用系统。
2. **不能通宵**：03:00–07:00 必须是禁止娱乐窗口（策略可把宵禁提前/延后，但不能缩短这个窗口）。
3. **连续 3 个自然日零学习**：第 4 天基础娱乐额度强制减半（`forced_tighten=true`），直到有学习完成记录。

除此之外，额度、宵禁、单次时长、黑名单、是否给奖励，全部由 Hermes 按当天对话决定。后端不设固定“每天 90 分钟”之类规则。

## 3. 核心循环

1. 宿主早上打开 App / 微信找呆：看今日任务、额度、体重、考研倒计时。
2. 完成任务（手动点完成，或开番茄计时到点自动完成）→ EXP、积分、五维、连击。
3. 想娱乐（游戏/视频）→ 问呆，或直接在 PC/手机申请 → 呆根据今天的学习、状态、对话给额度。
4. PC 执行器/手机软锁执行：到点断网、关游戏、必要时锁屏；所有使用和违规上报。
5. 晚上写日记，呆回一句；系统生成晚报；第二天额度重新由呆决定。

## 4. 功能范围

### 4.1 App（Android）
- **面板**：等级、经验条、五维雷达、今日额度环、任务、倒计时、快捷入口。
- **任务**：今日/本周/全部；新建、编辑、完成、推迟、重开；难度 1–5；分类（学习/身体/生活/心境/其他）；属性绑定。
- **专注**：25/45/60 分钟番茄；正计时；到点完成；白噪音可选（本地合成，不依赖网络）。
- **日记**：每天一篇，心情 1–5，标签；呆的回复只读展示；可回看。
- **身体**：体重、体脂、腰围；7/30/90 天趋势图；截图识别不做，宿主发微信给呆，呆写入。
- **统计**：7/30 天学习时长、任务完成率、额度使用、体重变化、热力图。
- **成就**：首次完成、连续 7 天、完成 50 个任务、减重 1kg、累计学习 100 小时等；仅展示，不弹窗打断。
- **系统**：呆的早晚报、事件日志、服务器状态、设置（通知、深色主题、数据导出、关于）。
- **桌面小组件**：4×2 面板、2×2 额度、1×1 等级、4×1 系统一句话、4×4 完整面板。
- **手机软锁**：宿主授予“使用情况访问”和“悬浮窗”后，检测娱乐 App（抖音/快手/B站/王者/和平/原神等，可配置）；额度为 0 或宵禁时盖一层全屏“系统锁定”，可申请延时；3 次强制关闭记违规。

### 4.2 PC 执行器（Windows，免安装 zip）
- 托盘常驻，隐藏控制台；计划任务登录自启（管理员，首次 UAC 一次）。
- 每 15 秒心跳；接收 lock/unlock/reload/kill 命令。
- 监控黑名单进程（默认 steam、WeGame、无畏契约、Deadlock、Minecraft、B站/抖音桌面端等）。
- 到点/超额度：先断开黑名单程序的出站网络（Windows 防火墙规则）+ 结束进程 + 托盘气泡；同一自然日第 3 次违规 → 调用 `LockWorkStation()` 锁屏。
- 所有动作上报事件；托盘菜单可“申请延时”（填分钟+理由，提交给呆）。
- 提供 `Install.ps1` / `Uninstall.ps1`、`config.json`、日志文件。
- 明示局限：管理员可杀进程/改防火墙/安全模式绕过；这是“高摩擦”，不是防黑客。

### 4.3 云端后端
- FastAPI + SQLite，部署在 159.75.236.90，Caddy 裸 IP 路径反代 `/kuangren-api`。
- 数据：profile、tasks、diary、weight、quota/policy、devices/events/commands、reports、achievements、audit。
- 每日 0 点结算；连续零学习检查；审计只增不删。
- 提供 `/export` 备份。

### 4.4 Hermes 插件
- 工具：`get_panel`、`list_tasks`、`create_task`、`complete_task`、`log_weight`、`write_diary_comment`、`set_daily_policy`、`grant_quota`、`get_stats`、`list_pending_requests`、`decide_request`、`write_report`。
- 呆在微信里可以直接：“今天背了 50 个单词” → 建任务并完成；“记一下 75.2” → 记体重；“我现在能玩多久” → 查额度/给额度；“今天太累了” → 调松策略。
- 早晚报：07:30 早报（倒计时、任务、额度、体重），22:30 晚报（完成率、学习时长、违规、明日建议）。
- 写操作二次确认；策略变更写审计；不能碰三条底线。
- 人设/记忆沿用现有 `SOUL.md` / `USER.md` / `MEMORY.md`，不覆盖。

## 5. 视觉与文案

- 背景：`#05070D`；面板：`#0B1220`；主色青 `#38F2E8`；次色紫 `#8B5CF6`；警告橙 `#FFB020`；危险红 `#FF4D5E`；文字 `#E8F1FF`，次要 `#7C8CA6`。
- 字体：中文系统 sans；数字/英文用等宽（monospace）。标题可有轻微发光，但不要满屏特效。
- 组件：细边框、扫描线/网格背景、切角卡片、进度条有分段刻度。
- 文案：系统口吻、短句、不卖萌、不鸡汤；示例：“今日额度 180 分钟。已用 35。别装没看见。”
- App 内不用“主人”，用“宿主”；不用“AI 助手”，用“系统”或“呆”。
