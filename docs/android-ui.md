# Android UI/交互规格 v1.0

## 0. 技术基线

- 包名：`com.ddw.kuangren`
- App 名：狂人日记
- minSdk 31，targetSdk 36，compileSdk 36
- Kotlin 2.2.0 + Compose；AGP 8.13.2；Gradle 8.13；JDK 17 目标
- 单 Activity + Compose Navigation；5 个底部 Tab
- 无 Hilt：`AppContainer` 手动依赖；`ViewModel` + `StateFlow`
- 网络：OkHttp 4.12 + kotlinx.serialization 1.7.3；缓存：SharedPreferences + JSON 文件（不引入 Room）
- 小组件：Glance 1.1.1
- 后台：WorkManager 2.10.1 每小时同步；前台服务仅用于番茄计时/软锁监控
- 所有 API 见 `docs/api.md`；服务端地址与 token 在 `BuildConfig`，也可在设置里改（长按版本号 5 次显示高级设置）

## 1. 设计令牌

```
background   #05070D
surface      #0B1220
surfaceAlt   #111B2E
border       #1E3A5F
primary      #38F2E8
secondary    #8B5CF6
warning      #FFB020
danger       #FF4D5E
text         #E8F1FF
textMuted    #7C8CA6
success      #4ADE80
```

- 圆角：卡片 4dp（切角感），按钮 4dp；不要大圆角。
- 背景：纵向渐变 + 极淡网格（Canvas 画 40dp 网格线，alpha 0.04）+ 顶部扫描线。
- 卡片：surface + 1dp border（primary alpha 0.25）；激活状态边框 primary alpha 0.7。
- 数字：`FontFamily.Monospace`，字重 Bold；中文：系统 sans。
- 动效：进度条 400ms；页面切换 200ms 淡入；不要弹跳。
- 无网络时顶部显示橙色细条：“离线 · 显示缓存”。

## 2. 导航

底部 5 个 Tab：
1. 面板（icon: Dashboard）
2. 任务（Checklist）
3. 日记（Book）
4. 身体（MonitorWeight）
5. 系统（Terminal）

路由：`panel`、`tasks`、`diary`、`body`、`system`；任务详情 `task/{id}`、专注 `focus/{taskId?}`、设置 `settings`。

## 3. 面板 Panel

从上到下：
1. **状态条**：左 `狂人日记 // SYSTEM ONLINE`（青色等宽小字），右 `2026-11-02 02:30`。
2. **倒计时卡**：`距 2027 考研初试` + `47` 大字 + `天`；副文案 `2026-12-19 / 12-20`。
3. **等级卡**：
   - 左：圆形等级环（Canvas，青→紫渐变），中心 `LV.1`；
   - 右：称号“初醒者”、EXP `0 / 100`、分段经验条；
   - 底部小字：`连续 4 天 · 累计学习 12h 30m`。
4. **五维雷达**：Canvas 五边形，标签 智力/体力/意志/专注/秩序；数值 0–100；无数据时画骨架。
5. **今日额度卡**：
   - 大环：剩余分钟 / 基础+奖励；中心 `175` `MIN`；
   - 状态：`额度可用` / `锁定中` / `宵禁`；
   - 一行：`已用 35 · 基础 180 · 奖励 30`；
   - 右侧按钮 `申请延时`（弹窗填 5–60 分钟 + 理由，提交 `POST /quota/requests`）。
6. **今日任务**：最多 5 条；每条左侧难度刻度（1–5 格），标题，右侧 `完成` 圆形按钮；点标题进详情；底部 `查看全部`。
7. **今日一句**：最新 Report/Notification 的第一行；没有则显示固定句：“今天也没有人来救你。很好。”
8. **快捷操作**：`开始专注`、`写日记`、`记体重`。

下拉刷新；首次加载 skeleton。

## 4. 任务 Tasks

- 顶部 segmented：今日 / 本周 / 全部 / 已完成。
- 任务卡片：
  - 左侧竖条颜色按分类：学习青、身体绿、生活橙、心境紫、其他灰。
  - 标题；副行 `难度 3 · 45min · 智力`。
  - 右侧完成按钮；长按/滑动弹出 `推迟到明天`、`重开`、`删除`。
- FAB `+` → 新建任务底部弹层：
  - 标题（必填）、描述（可选）
  - 分类 chips、难度 1–5、属性下拉、预计分钟、截止日期
  - 创建按钮
- 任务详情：标题、元信息、描述、番茄计时按钮、完成/重开/推迟。
- 完成时若任务有 `estimated_minutes >= 25`，弹确认：“直接完成，还是开番茄计时？” 两个按钮。
- 空状态：“今天没有任务。去跟呆说一句，或者自己加一个。”

## 5. 专注 Focus

- 圆环倒计时，中心 `25:00`；下方任务名。
- 按钮：暂停/继续、放弃、完成。
- 到点：震动 + 通知 + 自动 `POST complete`（如果绑定了任务）；否则只记一次专注。
- 白噪音：雨声/咖啡馆/风扇，用 AudioTrack 本地生成，不联网；默认关。
- 退出时若计时中，前台服务保活；通知栏显示剩余时间。

## 6. 日记 Diary

- 日期选择器（左右箭头，不能选未来）。
- 心情 5 个字符图标：`▁ ▂ ▄ ▆ █`（低到高），选中变青。
- 多行输入框，占位：“今天发生了什么？不用写给谁看。”
- 标签输入（回车添加）。
- 保存按钮；自动保存草稿到本地。
- 下方“呆的批注”卡片：只读，紫色左边框；没有则显示“呆还没看。晚上再说。”
- 历史：列表按日期倒序，显示心情、摘要、标签。

## 7. 身体 Body

- 顶部大数字：最新体重 `104.7` kg，右侧 `较 7 天前 -0.5`。
- 30 天折线图（Canvas）：青色线 + 渐变填充 + 目标线 85kg（虚线）。
- 指标卡：体脂、腰围、BMI（身高 181cm 写死默认，可设置）。
- `记录` 按钮：体重必填，体脂/腰围/备注可选；日期默认今天。
- 历史列表。
- 提示：“体脂秤截图可以直接发微信给呆就行，会帮你记。”

## 8. 系统 System

- **呆的消息**：Report 列表（早报/晚报/系统），卡片显示标题、时间、前 3 行；点击展开。
- **事件日志**：最近 20 条 Event（违规、锁屏、额度变动），红色/橙色标记。
- **统计**：本周学习分钟、完成任务数、完成率、额度使用；点击进详细页（热力图 + 每日柱状）。
- **成就**：网格，已解锁亮、未解锁灰。
- **设置**：通知开关、番茄时长、软锁开关与权限引导、数据导出（调用 `GET /export` 存文件）、服务器地址（高级）、关于/版本。
- 底部：`狂人日记 v1.0.0 · 数据在你自己服务器上`。

## 9. 小组件

所有小组件读取本地缓存（`WidgetCache`），由 WorkManager 每小时 + App 前台刷新；点击打开对应页面。

1. **4×2 面板**：左上 LV/称号，右上倒计时；中间额度环；底部今日任务 `2/5`。
2. **2×2 额度**：大数字剩余分钟，环形进度，状态文字。
3. **1×1 等级**：`LV.4` + 经验条。
4. **4×1 一句话**：`距考研 47 天 · 今日额度 175 分 · 任务 2/5`。
5. **4×4 完整**：等级、五维迷你雷达、额度、任务前 3 条。

深色背景，Glance 不支持渐变，用纯色 #05070D + 青色文字。

## 10. 手机软锁（App 软锁）

- 设置里开启后引导两个权限：
  1. 使用情况访问（`Settings.ACTION_USAGE_ACCESS_SETTINGS`）
  2. 悬浮窗（`Settings.ACTION_MANAGE_OVERLAY_PERMISSION`）
- 前台服务每 5 秒检查当前前台应用；命中娱乐包名且（额度为 0 或宵禁）→ 显示全屏 overlay。
- Overlay 内容：`系统锁定`、剩余时间/原因、`申请延时`（打开 App 提交请求）、`返回`。
- 娱乐包名默认：`com.tencent.tmgp.sgame`（王者）、`com.tencent.tmgp.pubgmhd`（和平）、`com.miHoYo.Yuanshen`、`com.bilibili.app.in`、`com.ss.android.ugc.aweme`、`com.smile.gifmaker`、`com.tencent.qqlive`、`com.qiyi.video`；可在设置里增删。
- 用户点“返回”/强行关闭后 5 分钟内再次打开同一 App，记一次违规；当天 3 次违规 → App 通知 + 上报事件 + 30 分钟冷却（冷却期内仍显示 overlay，但文案变“冷却中”）。
- 这是软锁，不防卸载/不防安全模式；设置页明确写。

## 11. 状态与错误

- 加载：骨架屏；错误：卡片 + `重试` + 错误码。
- 401：提示“token 失效，请在高级设置更新”。
- 离线：缓存可看；写操作进本地队列（最多 100 条），联网后按顺序重放；任务完成用 `Idempotency-Key`。
- 请求超时 10s；重试 2 次（指数退避）。

## 12. 验收

- 5 个 Tab 均可进入，无崩溃。
- 完成一个任务后面板 EXP/额度/任务数同步更新。
- 添加体重后 30 天图更新。
- 小组件添加后 1 分钟内显示真实数据。
- 软锁在模拟器/真机上能盖住娱乐 App（无真机时至少代码路径和权限引导完整）。
